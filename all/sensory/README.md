# sensory

Two skills that prototype before anything gets built. Each puts 3-5 real-looking options in front of you, built from your project's own assets, so you pick by eye or by ear instead of reviewing one guess.

| Skill | What it makes |
| --- | --- |
| [`visual-brainstorming`](visual-brainstorming) | One local page of side-by-side mockups (A-E), using your real fonts, tokens, images and components, with a desktop/mobile toggle. |
| [`sound-brainstorming`](sound-brainstorming) | One local page of synthesised Web Audio candidates with play buttons, built on your project's own sound helpers, with an ambient bed and a progress slider so you hear them in context. |

Both skills follow the same flow: read the repo, ask at most three questions, make the options, iterate on your pick, then hand off a build spec or paste-ready code. Nothing touches your codebase until you pick.

Install both:

```
$skill-starter install https://github.com/iice257/Skills/tree/main/all/sensory
```
